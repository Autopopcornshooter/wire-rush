# 구현 결정 — 0.5.1

사용자 피드백에 따라 수동 조준·한 줄 와이어로 통일했습니다. 최초 기획 원문은 `ORIGINAL_BRIEF.md`, 과거 구현은 Git 태그에 보존합니다.

## 착지 이력

`release_wire()`가 실제 연결된 줄을 해제할 때 플레이어의 `global_position.y`를 `last_release_height`에 기록합니다. 단위는 도로 y=0 기준 m이며 플레이어 원점(캡슐 중심)을 사용합니다. 연결 성립 자체·앵커 높이·해제 후 이동은 기록을 바꾸지 않습니다. 재발사 실패·비행 중 갈고리 취소·이미 해제된 줄 정리도 기록을 유지합니다. 부동소수점 경계 오차 0.00001m만 허용합니다.

줄 교체·가림·복귀의 실제 해제도 같은 함수를 사용합니다. 줄을 계속 잡은 채 도로에 닿으면 접촉 높이에서 자동 해제한 뒤 판정합니다. HUD의 `landing_height()`는 연결 중에만 현재 플레이어 높이로 해제 결과를 미리 보여주고, 이후 저장된 해제 높이를 보여줍니다.

도로는 `road` 메타데이터를 가진 충돌체입니다. 도로의 위쪽 면에 닿을 때 마지막 해제 당시 플레이어 높이가 5m를 넘으면 `die`로 직접 종료하므로 방어구·복귀 보호·연습 복구로 우회하지 않습니다. 건물·공중 장애물 접촉은 별도 장애물 충돌입니다.

일반 점프에는 높이 예외를 부여하고, 새로운 연결이 실제로 성립하면 예외를 해제합니다. 스케이트를 시작할 수 있는 새 연결 표시는 착지 시 소모합니다. 점프 자체가 이 표시를 재충전하지 않습니다. 최초 연결 전의 시작 낙하는 정지로 처리합니다.

## 마찰

60Hz 물리 프레임 안에서 2회 서브스텝을 사용합니다. 지상 스케이트 속력은 `max(0, speed - mu * gravity * dt)`로 감속합니다. 마찰 계수는 등급별 0.35/0.22/0.12이며 타이머는 없습니다. 조향은 감속 중인 벡터를 회전시켜 추가 속력을 만들지 않습니다. 속력이 0.15m/s 이하이면 정지합니다.

와이어의 예상 위치 제약과 충돌 sweep을 유지합니다. 마지막 줄 해제 자체는 속도를 바꾸지 않습니다. 제거한 기능은 자동 앵커 네트워크·두 줄 독립 상태·동시 사출·사출 업그레이드·관련 설정입니다.

## 건물과 장애물

건물 충돌체의 원점을 지면에 고정하고 메시·콜라이더의 중심과 높이를 바꿉니다. 벽에 부착한 임시 연결점은 이동하지 않습니다. 기본 높이 23~35m, 업그레이드 추가 높이 10/20/30m. 이미 생성된 청크와 미래 청크에 동일하게 적용합니다.

첫 128m 이후 도전 청크에는 14m 간격의 작은 공중 블록 4개가 있습니다. 크기 2.6×2.2×1.4m, x=-3.7/0/3.7m, y=6/12/18/24m를 순환합니다. 높이 업그레이드는 블록을 +8/+16/+24m 이동시킵니다. 넓은 도로 차단벽은 제거했습니다. 연습 모드에는 장애물을 생성하지 않습니다.

공중 장애물은 `hazard`와 `hookable`을 동시에 가집니다. 표면 조준의 사거리·최소 2.5m 높이·줄 경로 가림 검사를 그대로 적용합니다. 연결점은 맞힌 충돌체의 자식이며, 장애물이 높아지면 연결점도 따라갑니다. 착지 이력은 앵커 움직임과 무관하게 플레이어의 해제 높이를 사용합니다. 연결 중인 청크는 정리에서 보호합니다.

## 남은 검증

자동 검사는 위치·속도 fixture와 실제 충돌 이동을 함께 사용합니다. 연속 주행 검사는 벽에 수동 위치를 지정하는 자동 입력으로 장애물 없는 연습 구간을 이동합니다. 사람의 자유 조작, 모든 장애물 조합, 상층 경로의 공정성까지 검증했다는 의미는 아닙니다. 카메라는 이전 먼 설정을 유지합니다.
