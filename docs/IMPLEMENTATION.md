# 구현 결정 — 0.2.1

원문은 `ORIGINAL_BRIEF.md`에 보존합니다. 본 문서는 실제 구현과 후속 과제를 구분합니다.

## 0.2.1 변경

- 기본 앵커 높이를 10/12m에서 16/18m로 상향. 고층 앵커는 18m 기준 추가 높이를 적용하며 새 건물 높이도 앵커를 수용하도록 상향.
- `Rider`의 연결 상태에서 활성 마우스 버튼이 줄을 소유하면 자동으로 감음. 별도 reel 입력 인자를 제거해 자동/직접 조준, 일반 플레이/검증 모두 동일한 동작을 사용.
- 마우스 버튼 해제 시 기존 관성 해제 동작 유지. Shift 입력과 재개 시 Shift 해제 요구를 제거. 한국어·영어 안내와 장비 설명 갱신.
- 직접 조준은 높은 건물 벽을 자유롭게 선택할 수 있고 최소 높이 2.5m 제한은 유지. 자동 앵커의 높이를 강제로 적용하지 않음.

## 0.2.0 변경

- 기본 언어는 한국어. 설정에서 영어와 즉시 전환하며 기존 구간 표지도 갱신. Noto Sans KR 글꼴과 OFL 라이선스를 포함.
- 자동 조준의 동작을 유지하고 직접 조준을 추가. 카메라→커서 광선의 첫 충돌이 건물일 때 플레이어 사거리·최소 높이·실제 줄 경로를 검사.
- 직접 조준으로 만든 앵커는 맞힌 건물의 자식 노드. 연결 중 위치가 고정되며 원점 이동과 청크 보호를 그대로 적용. 해제·재연결 시 임시 노드를 정리.
- 스윙 중 새 지점을 가리키고 반대 버튼으로 재연결. 잘못된 변경은 현재 줄을 유지. 이전 버튼을 놓아도 새 줄은 유지.
- 마우스 입력은 순서대로 큐에 넣고 물리 프레임에서 조회·연결·해제를 처리. 한 프레임 안의 누름/놓기와 정지 진입 시 대기 입력을 처리.
- 설정은 별도 `settings.cfg`에 저장. 기록 저장 파일을 덮어쓰지 않음. 연습/도전 중에는 Esc로 정지 후 설정 가능.
- 기록은 현재 두 조준 모드가 공유. E 양측 사출은 두 모드 모두 기존 전방 앵커에 연결.
- 글꼴은 정수 OpenType 태그 `2003265652`(wght)로 두께 500 지정. 해당 엔진에서는 문자열 태그로 지정했을 때 얇은 기본 두께가 남아 실제 화면에서 확인 후 수정.

레이 조회의 물리 프레임 처리와 카메라 광선은 [Godot 공식 문서](https://docs.godotengine.org/en/stable/tutorials/physics/ray-casting.html)를 따릅니다.

60Hz 물리 프레임 안에서 2회 서브스텝을 실행합니다. 예상 위치가 줄 반경 밖에 있을 때만 길이 제약을 적용하고, 모든 최종 이동에 `move_and_collide` sweep을 사용합니다. 갈고리 비행 중에는 제약을 적용하지 않습니다. 줄 해제 자체는 속도를 수정하지 않습니다. 기본 도로는 평지입니다.

## 원문 대비 프로토타입 결정

- 이름: Wire Rush. 로컬 폴더와 씬 루트의 초기 작업명은 WireSwing.
- Godot 4.7.1 Compatibility 렌더러, Windows x64. 외부 아트 구매 없이 도형과 합성음을 사용.
- 출발은 y=6m, 전진 12m/s 공중 출발. 지상 재도약도 가능. 도입부의 대기 시간을 줄임.
- 초기 앵커 16m 간격은 연속 주행 검사에서 낙하 복구가 잦아 기본 8m 간격으로 조정. 앵커 자동 선택은 가까운 전방·사거리·시야 통과 후보를 우선.
- 도로 폭 14m, 앵커 x=±6.1m, 기본 높이 16/18m. 최대 속도35m/s. 초기 4청크(256m)는 장애물 없음. 안전 시간은 속도에 따라 달라짐.
- 64m 청크 패턴: 직선, 낮은 차단물, 상부 차단물, 넓은 앵커 간격, 저공 보상, 재도약 차단물. 현재 순서는 결정적 반복이며 진입 속도별 연결 태그 탐색기는 미구현.
- 장애물 바닥 예고는 60m 앞부터 배치. 카메라 가림·속도별 실제 인지 시간은 사람의 확인 필요.
- 현재 구덩이는 생성하지 않음. 낙하 경계 복구 처리만 존재.
- 최대 능력 이후 XP 팝업을 생략. XP 요구량 지수는 9레벨부터 고정해 무한 증가를 제한.
- 별도 달리기 속도·획득 반경 업그레이드, 영구 성장, 음량 설정, 난도 자동 상승, 로프 감기는 후속 범위.
- 기본 스케이트 만료는 지상 속도로 감속하며, 장비가 없거나 타이밍 실패한 저충격 착지는 0.6초 넘어짐.
- 방어구는 충돌 위치 뒤 5m, 높이6m 도로 중앙으로 복구. 구덩이와 일반 지형용 안전 복구점 탐색은 후속 과제.
- Esc/포커스 상실/레벨업 이후 와이어를 해제하고 모든 동작 버튼을 놓은 뒤 1초 카운트다운. 정지 상태의 속도·재사용 시간은 유지.

## 제한과 다음 기준

기능 통합 검사는 초기 위치/속도를 지정하는 fixture와 실제 물리 이동을 함께 사용합니다. 이는 사람이 처음부터 플레이한 결과가 아닙니다. 연속 주행 검사는 자동 입력으로 장애물 없는 Practice를 주행하며, 충돌 복구 없이 이동 가능한 기본 연결성을 검사합니다.

6종 장애물 청크의 모든 연결·능력 조합과, 저공 스윙→슬라이드→재연결 5회 연속은 아직 통과를 주장하지 않습니다. 다음 튜닝의 최우선 기준입니다.
