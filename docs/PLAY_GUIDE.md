# Wire Rush 0.1.0 플레이 안내

`WireRush.exe` 실행 → **Practice**로 첫 조작을 연습하세요.

## 공중 이동

1. 시작 시 이미 공중에서 전진합니다. LMB 또는 RMB를 누른 채 Shift를 누릅니다.
2. 원형 표시는 해당 버튼으로 연결할 다음 앵커입니다. 줄은 갈고리가 도착한 뒤 연결됩니다.
3. 앵커를 지나 앞으로 날아갈 때 버튼을 놓습니다. 반대 버튼으로 다음 앵커를 잡을 수 있습니다.
4. Shift는 실제 줄 길이를 줄입니다. 과하게 감으면 앵커 근처에서 원을 그리므로 적절히 풀고 전환하세요.
5. 땅에서 넘어졌다면 잠시 자동 복구를 기다린 뒤 Space로 점프하고 줄을 거세요.

## 스케이트 슬라이드

- Practice에는 처음부터 스케이트가 있습니다. Run에서는 첫 레벨업 후보로 등장합니다.
- 바닥 직전 수직 낙하 속도가 **4m/s 이하**, 수평 속도 **8m/s 이상**이어야 합니다.
- 착지 **0.15초 전~0.15초 후**에 연결된 와이어를 놓으면 속도를 보존하며 최대 25m 슬라이드합니다.
- 안전한 낮은 스윙을 만든 뒤 바닥 근처에서 줄을 놓으세요. 높은 곳에서 그냥 떨어지면 치명 충돌입니다.
- HUD의 `SOFT LANDING`은 현재 수직 속도 기준입니다. 이후 낙하 가속까지 보장하는 예측 표시는 아닙니다.
- 슬라이드 중 Space를 누르면 속도를 유지하며 재도약합니다. 공중에서 1.5m 이상 올라야 다음 슬라이드가 재충전됩니다.

## 성장과 종료

새로 전진한 거리와 주황색 아이템으로 경험치를 얻습니다. 레벨업은 물리와 재사용 타이머를 멈춥니다. 1/2/3 또는 카드를 클릭해 능력을 선택하고, 조작 버튼을 모두 놓으면 1초 뒤 재개됩니다.

E 양측 사출은 장비를 얻은 뒤 양쪽 앵커가 유효할 때만 발동합니다. 방어구는 치명 충돌을 한 번 막습니다. 고층 연결망은 앞으로 생성될 청크에만 높은 앵커를 추가합니다.

Run의 최고 거리는 `%APPDATA%\Godot\app_userdata\Wire Rush\records.cfg`에 저장됩니다. Practice와 자동 검증은 최고 기록을 바꾸지 않습니다.

Esc 일시정지, R 즉시 재시작. 결과 화면에서 Run Again 또는 Main Menu를 선택할 수 있습니다.

현재 UI는 영어입니다. 이 버전은 기본 도형을 사용한 조작 검증용 프로토타입입니다.
