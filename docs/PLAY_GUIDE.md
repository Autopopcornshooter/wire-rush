# Wire Rush 0.13.0 플레이 안내

`WireRush.exe`를 실행하고 게임 시작 또는 연습 모드를 선택하세요. 설정에서 한국어/English, 해상도, 전체 화면, 효과음 음량을 바꿀 수 있습니다.

## 조작

| 입력 | 동작 |
|---|---|
| 왼쪽/오른쪽 마우스 유지 | 조준한 건물·정지 드론에 와이어 발사, 연결 후 자동 감기 |
| 활성 마우스 버튼 해제 | 와이어를 놓고 관성 비행 |
| 반대 마우스 버튼 | 한 줄을 새 연결점으로 교체 |
| Space | 지상·스케이트 점프, 코어 해금 후 공중 이중 점프 |
| W | 지상 전진 걷기 |
| A/D | 지상 좌우 이동·공중 조향·스케이트 방향 전환 |
| G | 대기 중인 업그레이드를 순서대로 선택 |
| 1/2/3 | 업그레이드 카드 선택 |
| Esc | 일시정지·설정 |
| R | 재시작 |

와이어는 수동 한 줄입니다. 청록 조준선은 연결 가능, 붉은 조준선은 연결 불가입니다. 기본 사거리는 플레이어 기준 30m이며, 먼 조준은 사거리 안의 실제 표면으로 보정됩니다. 작은 청록 원이 실제 연결점입니다. 바닥·하늘·차량·보스 발사 로봇에는 연결할 수 없습니다. 연결된 정지 드론 자체는 줄 가림에서 제외되지만 다른 물체가 줄을 가리면 해제됩니다.

카메라는 약 5m 거리에서 캐릭터를 따라가고 마우스로 시점을 조절합니다. 벽 점프와 두 줄 동시 사출은 비활성화되어 있습니다.

## 도로 착지와 스케이트

실제로 연결된 와이어를 **놓는 순간의 플레이어 높이**가 기준입니다. 앵커 높이나 착지 순간 높이로 판정하지 않습니다.

- 5m 이하에서 해제: 도로 착지 생존. 스케이트 코어·충전량·충분한 수평 속도가 있으면 슬라이드합니다.
- 5m 초과에서 해제: 도로 착지 시 게임오버. 방어구·보호·연습 복구로 막을 수 없습니다.
- 지상 점프 후 새 와이어 연결 없이 착지: 높이 규칙의 예외로 안전합니다.
- 해제 후 최고 높이나 단순 재착지는 해제 기록을 바꾸지 않습니다. 다시 연결한 줄을 낮게 해제하면 새 기록이 적용됩니다.
- 줄을 잡은 채 도로에 닿으면 접촉 높이에서 자동 해제합니다. 처음의 와이어 없는 시작 낙하도 안전하게 착지합니다.

새 와이어 연결 후 낮게 해제한 착지에서 스케이트를 시작합니다. 점프·재착지만으로 슬라이드를 새로 만들 수는 없습니다.

| 스케이트 코어 등급 | 완전 충전 사용 시간 | 완전 재충전 시간 |
|---|---:|---:|
| 1 | 2초 | 4초 |
| 2 | 3.5초 | 7초 |
| 3 | 5초 | 10초 |

충전량은 계속 유지됩니다. 와이어 연결·해제, 점프·착지로 초기화되지 않습니다. 슬라이드 중 소모하고 그 외에는 재충전합니다. 일반 업그레이드로 소모·재충전을 개선할 수 있습니다. A/D는 스케이트의 방향을 바꾸며, 기본 슬라이드는 충전/시간이 끝나면 정지합니다. STREET SURFER 시너지는 종료 시 일부 관성을 남깁니다.

## 성장과 장애물

새로 전진한 거리와 수집품으로 XP를 얻습니다. 레벨업은 즉시 게임을 멈추지 않고 선택을 대기시킵니다. G를 누르면 선택 중에만 멈춥니다. 일반 업그레이드는 WIRE/MOBILITY/MOMENTUM/SURVIVAL 네 카테고리이며 Lv5/10/15…에는 이중 점프·롤러스케이트·충격 방어구 중 코어를 선택합니다. 대기열은 NORMAL/CORE 순서를 유지합니다.

이중 점프는 코어를 획득해야 사용할 수 있고 등급별 재사용 대기는 10/7/5초입니다. 점프 높이 업그레이드와는 별개입니다. 착지해도 재사용 대기는 초기화되지 않습니다. 조건에 맞는 투자를 하면 SLINGSHOT, STREET SURFER, SKY RUNNER 시너지가 자동 적용됩니다.

정지 경찰 드론은 와이어 연결이 가능하지만 몸 충돌은 위험합니다. 차량과 보스 발사 로봇도 충돌 위험물입니다. 방어구가 있으면 충전 1개를 소비하고 잠시 보호받습니다. 기본 보호는 2초이며 관련 업그레이드로 늘어납니다. 방어구 없이 위험한 충돌을 하면 게임오버입니다. 건물 벽 자체는 안전합니다. 일시정지 복귀가 새 보호를 주지는 않습니다.

## City와 보스

도시는 플레이어 업그레이드와 별개로 0/500/1000/2000m에서 난이도가 증가합니다. 건물 높이는 플레이어 업그레이드가 아니며, 이미 생성된 청크는 바뀌지 않습니다. 건물은 첫 128m 이후 한쪽이 번갈아 비는 배치입니다. Sky Gap에서는 건물 대신 드론 연결 경로가 남고, Traffic Surge에서는 일시적으로 차량이 많아집니다.

3200m부터 Police Interceptor를 피해 4700m까지 이동합니다. HP나 공격 버튼은 없습니다.

- SIDE LASER: 한쪽 건물과 그쪽 도로 일부를 차단합니다. 반대쪽을 이용하세요.
- HEIGHT LASER: 사용 높이의 위 또는 아래 절반을 차단합니다. 열려 있는 높이로 이동하세요.
- ROBOT BARRAGE: 보스가 3기를 순차 발사합니다. 발사 후에는 직선으로 움직이며 계속 추적하지 않습니다.

A/B는 실제 위험 범위와 같은 붉은 해치 경고가 3회 점멸한 뒤 2초간 활성화됩니다. 발사 로봇은 주황색 몸체 표시와 핀으로 정지 드론과 구분합니다. 보스와 휴식 구간에는 Sky Gap/Traffic Surge가 겹치지 않습니다. 4700~5100m는 검문소가 있는 휴식 구간입니다. 5100m 도시 경계를 넘으면 **도시 탈출 완료** 결과 화면이 표시되며 다시 도전하거나 메뉴로 돌아갈 수 있습니다. 다음 챕터 플레이는 시작하지 않습니다. 짧은 Signal 자막은 게임을 멈추지 않습니다.

연습 모드는 스케이트를 제공하고 양쪽 건물을 유지합니다. 공중 장애물·차량·보스·성장은 제외됩니다. 높은 와이어 해제 후 도로 착지의 게임오버 규칙은 동일합니다.

설정과 기록은 Godot의 `user://`에 저장됩니다. 연습과 `--test` 검증은 최고 기록 파일을 갱신하지 않습니다.
