# Wire Rush 0.5.1 플레이 안내

`WireRush.exe`를 실행하고 연습 모드 또는 기록 도전을 시작하세요. 설정에서 한국어/English를 바꿀 수 있습니다. 이 버전은 **수동 조준·와이어 1개**만 사용합니다.

## 와이어 조작

1. 건물 벽이나 공중 장애물의 원하는 지점을 가리킵니다. 청록 조준선은 연결 가능, 붉은 조준선은 연결 불가입니다.
2. 왼쪽 또는 오른쪽 마우스 버튼을 유지하면 해당 지점으로 갈고리를 발사합니다. 도착하면 줄이 연결되고 자동으로 감깁니다.
3. 다른 지점을 가리키고 반대 버튼을 누르면 기존 줄을 새 지점으로 교체합니다. 두 줄을 동시에 유지하지 않습니다.
4. 현재 줄을 건 버튼을 놓으면 해제됩니다. 이전 버튼을 놓아도 새 줄은 끊기지 않습니다. 잘못 조준한 재발사는 기존 줄을 유지합니다.
5. 기본 사거리는 플레이어 기준 30m, 최소 연결 높이는 2.5m입니다. 바닥·하늘에는 연결할 수 없습니다. 플레이어와 연결점 사이가 가려지면 연결할 수 없고, 사용 중인 줄이 막히면 해제됩니다.

카메라는 캐릭터 뒤 12m·위 4.5m 기준입니다. 자동 앵커 선택, 와이어 개수 설정, E 양측 사출은 없습니다. 이전 설정 파일에 남은 값도 무시합니다.

## 도로 착지: 줄을 놓는 순간의 플레이어 높이

- **실제로 연결된 와이어를 해제하는 순간의 플레이어 높이**를 기억합니다. 앵커를 박은 표면 높이로 판정하지 않습니다.
- 플레이어 높이 **5m 이하에서 해제**: 생존. 스케이트와 새로운 착지용 연결이 있으면 슬라이드, 아니면 정지합니다.
- 플레이어 높이 **5m 초과에서 해제**: 도로에 부딪히면 게임오버. 방어구·복귀 보호·연습 모드의 자동 복구도 이 판정을 무시하지 못합니다.
- 예: 18m 앵커에 연결했어도 플레이어가 4m일 때 놓으면 생존합니다. 4m 앵커에 연결했어도 플레이어가 8m일 때 놓으면 착지 시 게임오버입니다.
- 해제 후 올라간 최고 높이와 착지 순간 높이는 기록을 바꾸지 않습니다. 다시 실제로 연결한 줄을 플레이어 높이 5m 이하에서 놓으면 안전한 기록으로 바뀝니다. 갈고리가 날아가는 중 취소하거나 조준에 실패해도 기존 기록은 유지됩니다.
- 줄 교체·경로 가림·일시정지 복귀도 실제 연결을 해제하면 그 순간의 플레이어 높이를 기록합니다. 이미 놓은 줄을 다시 정리하는 처리는 기록을 덮어쓰지 않습니다.
- 줄을 계속 잡은 채 도로에 닿으면 접촉한 플레이어 높이에서 자동 해제하고 착지합니다.
- 벽의 청록색 가로선은 5m 높이 기준입니다. HUD는 연결 중 현재 플레이어 높이와 지금 놓았을 때의 위험, 해제 후에는 마지막 해제 높이와 착지 위험을 표시합니다. 조준선의 '지점 높이'는 연결할 표면의 높이입니다.
- 아직 한 번도 연결하지 않은 시작 낙하는 안전하게 정지합니다. 건물·공중 장애물의 몸 충돌은 도로 착지와 별도입니다.

## 점프 예외와 스케이트

**Space로 지상·스케이트에서 점프한 뒤 와이어에 새로 연결하지 않으면**, 5m보다 높이 뛰어도 안전하게 착지합니다. 점프 중 새로운 연결이 성립하면 예외가 해제되고 이후 줄을 놓을 때의 플레이어 높이로 판정합니다.

스케이트 착지에는 새로운 연결과 플레이어 높이 5m 이하에서의 해제가 필요합니다. 착지 때 한 번 사용되므로 **스케이트 → 점프 → 연결 없이 착지**는 정지합니다. **스케이트 → 점프 → 재연결 → 플레이어 높이 5m 이하에서 해제 → 착지**는 다시 슬라이드합니다.

| 스케이트 등급 | 마찰 계수 | 초당 감속량 |
|---|---:|---:|
| 1 | 0.35 | 7m/s |
| 2 | 0.22 | 4.4m/s |
| 3 | 0.12 | 2.4m/s |

마찰 계수 × 중력(20m/s²)만큼 속도를 줄입니다. 지속시간 타이머는 없으며 진입 속도가 높을수록 더 오래 미끄러집니다. 속도가 거의 0이면 정지합니다. A/D는 진행 방향을 보정하고 속도를 만들어내지 않습니다. 장애물과 접촉하면 별도 충돌 판정을 받습니다.

## 건물 높이와 공중 장애물

높은 건물 업그레이드는 기본 건물 높이 23~35m에 등급별 **10 / 20 / 30m**를 추가합니다. 현재 보이는 건물과 앞으로 생성될 건물 모두 적용되며 충돌 형상도 높아집니다. 이미 건물 벽에 걸린 연결점은 이동하지 않습니다.

기록 도전은 첫 128m 이후 구간마다 작은 공중 블록 4개가 등장합니다. 블록 크기는 2.6 × 2.2 × 1.4m, 기본 중심 높이는 6/12/18/24m이고 좌우·높이를 엇갈리게 배치합니다. 건물 업그레이드에 따라 장애물 높이도 **8 / 16 / 24m** 올라가 상층 경로를 방해합니다.

공중 블록 표면에도 와이어를 걸 수 있습니다. **걸 수 있다는 것이 몸으로 부딪혀도 안전하다는 뜻은 아닙니다.** 장애물이 업그레이드로 올라가도 착지 기준은 줄을 놓을 때의 플레이어 높이입니다.

## 성장·보호·저장

새로 전진한 거리와 아이템으로 경험치를 얻고, 레벨업 때 스케이트·방어구·건물 높이·사거리·감기·갈고리·점프 업그레이드를 고릅니다. 방어구는 장애물 충돌을 막고 1회 충전을 소비합니다.

Esc·포커스 상실·레벨업 복귀는 버튼을 놓고 1초 카운트다운 후 재개됩니다. 이후 2초 보호는 **장애물 충돌에만** 적용되며 5m 초과에서 줄을 놓은 뒤 도로 착지는 여전히 게임오버입니다.

연습 모드는 스케이트를 제공하고 공중 장애물을 생성하지 않습니다. 일반 장애물 충돌·경계 추락에는 복구가 있지만, 5m 초과에서 줄을 놓은 뒤 도로 착지는 동일하게 게임오버입니다. 연습과 자동 검증은 최고 기록을 갱신하지 않습니다.

언어는 `%APPDATA%\Godot\app_userdata\Wire Rush\settings.cfg`, 기록은 같은 폴더의 `records.cfg`에 저장합니다. 이전 버전의 최고 거리 숫자는 유지되지만 규칙이 바뀌었으므로 직접적인 난도 비교에는 적합하지 않습니다.
