# Wire Rush 0.3.0 플레이 안내

`WireRush.exe` 실행 → **연습 모드(Practice)**로 첫 조작을 연습하세요.

## 언어와 조준 방식

메인 메뉴 **설정(Settings)** 또는 **Esc → 설정**에서 언어를 한국어/English로 바꿀 수 있습니다. 메뉴·HUD·장비 카드·실패 메시지·구간 표지에 즉시 적용됩니다. 한국어 글꼴이 실행 파일에 포함되어 있습니다.

같은 화면에서 **자동 조준/직접 조준**을 선택합니다. 선택 내용은 `%APPDATA%\Godot\app_userdata\Wire Rush\settings.cfg`에 저장됩니다. 최고 기록 파일과 분리되어 있습니다.

## 원하는 위치로 직접 스윙하기

1. 설정에서 **직접 조준**을 선택하고 연습 모드를 시작합니다.
2. 커서를 건물 벽의 원하는 높이와 위치로 옮깁니다. 청록색 조준선은 연결 가능, 붉은색은 연결 불가입니다. 거리 또는 실패 이유가 표시됩니다.
3. **왼쪽 또는 오른쪽 버튼을 유지**해 그 지점에 와이어를 겁니다. 연결되면 자동으로 줄을 감습니다. 기존 빛나는 앵커가 없는 벽에도 연결할 수 있습니다.
4. 스윙 중 **다른 지점을 가리킨 뒤 반대쪽 버튼을 누르면** 연결 위치가 바뀝니다. 이미 연결한 점은 커서를 움직여도 고정됩니다.
5. 현재 줄을 건 버튼을 놓으면 해제됩니다. 이전 줄의 버튼을 놓는 동작은 새 줄을 끊지 않습니다. 사거리 밖이나 가려진 지점으로의 변경은 기존 줄을 유지합니다.

기본 사거리는 플레이어 기준 30m이며 벽 높이 2.5m 이상이어야 합니다. 바닥·하늘·장애물에는 연결할 수 없습니다. 카메라에서 보이더라도 플레이어와 벽 사이가 가려지면 연결할 수 없습니다. 연결 후 경로가 막히면 기존 규칙대로 해제됩니다. E 양측 사출은 두 모드 모두 기존 전방 앵커를 사용합니다.

## 자동 조준의 공중 이동

1. 시작 시 이미 공중에서 전진합니다. LMB 또는 RMB만 유지하세요. 갈고리가 연결되면 자동으로 줄을 감습니다.
2. 원형 표시는 해당 버튼으로 연결할 다음 앵커입니다. 줄은 갈고리가 도착한 뒤 연결됩니다.
3. 앵커를 지나 앞으로 날아갈 때 버튼을 놓습니다. 반대 버튼으로 다음 앵커를 잡을 수 있습니다.
4. 기본 앵커는 16~18m 높이에 있습니다. 줄은 버튼을 유지하는 동안 최소 3m까지 감깁니다. 너무 오래 붙잡기보다 앵커를 지나며 다음 지점으로 전환하세요. Shift는 사용하지 않습니다.
5. 땅에 닿으면 게임오버 없이 정지합니다. Space로 점프하거나 마우스로 다시 연결하세요. 카메라는 캐릭터 뒤 6m·위 2.2m를 따라가며 가까이서 조준할 수 있습니다.

## 스케이트 슬라이드

- Practice에는 처음부터 스케이트가 있습니다. Run에서는 첫 레벨업 후보로 등장합니다.
- **스케이트가 없으면 착지 즉시 정지**합니다. 높은 곳에서 떨어져도 바닥 착지만으로 사망하거나 방어구를 소비하지 않습니다.
- 스케이트가 있으면 착지 때의 수평 속도를 **1등급 2초 / 2등급 3.5초 / 3등급 5초** 동안 유지합니다. 줄을 놓는 타이밍 조건은 없으며 착지 시 자동으로 줄을 해제합니다.
- HUD에 남은 유지 시간이 표시됩니다. 시간이 끝나면 멈추며, 그 전에 Space로 점프하거나 마우스로 다시 연결할 수 있습니다.
- A/D로 방향을 보정해도 평지에서 수평 속력은 유지됩니다. 장애물 충돌은 별도입니다.
- 공중에서 캐릭터 중심이 높이 2.3m 이상 올라야 다음 스케이트 착지가 재충전됩니다. 같은 착지로 시간을 무한 갱신할 수 없습니다.

## 양측 사출과 복귀 보호

- 양측 사출 장비를 얻고 **40m 이내에 보이는 왼쪽·오른쪽 전방 앵커가 모두 있을 때 E**를 누릅니다. HUD에 준비 상태가 표시됩니다. 직접 조준 모드에서도 사출은 기존 전방 앵커 쌍을 사용합니다.
- 발동 즉시 **플레이어 → 두 앵커 중간점** 방향으로 속도를 바꿉니다. 기존 낙하 방향과 무관하며 돌진 중 중력·A/D가 방향을 바꾸지 않습니다.
- 등급별 속도는 **28 / 32 / 35m/s**, 최대 **0.65초**간 돌진합니다. 가까운 중간점은 1.5m 앞에서 돌진을 마칩니다. 돌진 중 장애물을 통과하고 피해를 받지 않습니다.
- 종료 후 관성을 유지하며 공중 이동으로 돌아옵니다. 빠져나올 여유로 0.3초 보호가 더 남습니다. 재사용 대기는 10초이며 앵커가 부족하면 소비하지 않습니다.
- **Esc·포커스 상실·레벨업에서 복귀하면 2초 무적**입니다. 기존 1초 카운트다운이 끝나 실제 플레이가 재개될 때 시작하고 HUD에 남은 시간이 표시됩니다. 일반 복귀 보호 중에는 장애물을 통과하지 않고 충돌면을 따라 멈추거나 미끄러집니다.

## 성장과 종료

새로 전진한 거리와 주황색 아이템으로 경험치를 얻습니다. 레벨업은 물리와 재사용 타이머를 멈춥니다. 1/2/3 또는 카드를 클릭해 능력을 선택하고, 조작 버튼을 모두 놓으면 1초 뒤 재개됩니다.

방어구는 장애물의 치명 충돌을 한 번 막습니다. 보호 시간이 없을 때 정면 장애물 충돌이나 도로 밖 추락은 도전을 종료할 수 있습니다. 고층 연결망은 앞으로 생성될 청크에만 높은 앵커를 추가합니다.

Run의 최고 거리는 `%APPDATA%\Godot\app_userdata\Wire Rush\records.cfg`에 저장됩니다. Practice와 자동 검증은 최고 기록을 바꾸지 않습니다.

Esc 일시정지, R 즉시 재시작. 결과 화면에서 Run Again 또는 Main Menu를 선택할 수 있습니다.

이 버전은 기본 도형을 사용한 조작 검증용 프로토타입입니다. 직접 조준의 체감 난이도와 6종 장애물의 모든 조합은 추가 플레이 검증 대상입니다.
