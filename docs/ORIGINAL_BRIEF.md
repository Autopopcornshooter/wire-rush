# 3D 무한 와이어 스윙 — 기획·개발 전달 프롬프트 v0.1

아래 내용을 게임 기획자·개발 AI에게 전달한다. 사용자 원안을 보존하되, 제안한 수치와 조작은 테스트 전 가설이다. 현재 요청은 기획이며 구현 완료를 의미하지 않는다.

## 복사해서 전달할 프롬프트

너는 소규모 3D 액션 게임의 기획자이자 게임플레이 개발자다. 다음 요구사항으로 구현 가능한 상세 기획서를 작성하라. 기능을 나열하는 데 그치지 말고 스윙, 관성, 장애물 회피, 경험치 선택, 지상 슬라이드가 하나의 플레이로 연결되게 설계하라. 재미가 충돌하는 부분은 이유와 해결책을 명시하라. 확정 요구와 제안 사항을 구분하고, 부족한 정보는 합리적 가정으로 진행하라.

### 1. 목표와 범위
- Flappy Bird처럼 직선으로 끝없이 진행하며 최고 기록에 도전하는 싱글플레이 게임이다.
- 그래픽과 공간은 3D다. 길 양옆에 건물이 있고 캐릭터가 와이어를 걸어 스윙한다.
- 핵심 재미는 ‘걸기 → 최저점에서 속도 얻기 → 적절한 순간 놓기 → 다음 연결점 잡기’의 리듬이다.
- 지상에서는 ‘낮게 진입 → 와이어 해제 → 롤러스케이트 질주 → 점프 → 재연결’로 공중 동작을 이어간다.
- 세션 내 레벨업으로 능력을 선택하는 로그라이트 성장을 결합한다. 최초 버전은 사망 시 경험치·능력을 초기화하고 최고 기록과 설정만 저장한다. 영구 능력치 성장은 별도 제안으로만 다룬다.
- 최소 비용 기준: Godot 4 계열, PC 키보드·마우스, 로우폴리 도시, 오프라인 플레이를 기본 가정으로 한다. 웹 배포는 첫 버전의 필수 조건이 아니다.
- 기존 프로젝트 통합은 가정하지 않는다. 신규 소규모 프로젝트 기준으로 기획한다.

### 2. 기록과 목표
- 주 기록은 진행축의 최고 도달 거리(m)로 한다. 이동 궤적의 총 길이가 아니다.
- 점수 = max(이전 최고 진행 좌표, 현재 진행 좌표) - 시작 좌표. 되돌아오기·제자리 스윙은 추가 점수를 주지 않는다.
- 빌딩은 좌우 건물 한 쌍으로 구성한 블록을 통과했을 때 1블록으로 집계한다. 보조 기록에만 사용한다.
- 결과 화면: 최고 거리, 이번 거리, 최고 속도, 통과 블록, 퍼펙트 슬라이드 횟수, 이번 빌드.
- 초기 목표 플레이 길이는 초보 30~90초, 숙련자 3~5분 이상으로 가정한다. 시간 제한은 없다.

### 3. 카메라와 조작 제안
- 약간 위에서 바라보는 후방 3인칭 추적 카메라. 도로 앞쪽과 다음 앵커가 보여야 한다.
- 자유 비행을 구현하지 말고 도로 폭 안에서 제한적으로 좌우 이동하도록 한다. 기본 전진 달리기는 자동이다. 공중에서는 관성이 주가 되고 약한 보정만 허용한다.
- 마우스 왼쪽 버튼: 왼쪽 앵커에 발사·유지. 오른쪽 버튼: 오른쪽 앵커에 발사·유지. 버튼을 놓으면 해제한다.
- 기본 와이어는 동시 1개다. 반대 버튼을 누르면 기존 것을 해제하고 새 와이어를 발사한다. 양쪽 동시 입력은 마지막 유효 입력을 우선하며 이중 와이어로 오인하지 않는다.
- 앵커는 사거리·시야·전방 여부를 통과한 후보 중 자동 선택한다. 다음 연결 대상을 발사 전에 표시하고, 발사 후에는 해당 대상으로 고정한다. 유효 대상이 없으면 분명한 실패 피드백을 준다.
- A/D: 제한적 좌우 보정. Space: 지상 점프. E: 양측 사출 장치. Shift: 연결 중 와이어 길이 줄이기.
- 자동 조준은 제작 난도와 조작 부담을 낮추기 위한 제안이다. 자유 조준은 후속 실험으로 분리한다.
- 속도감은 제한적인 시야각 변화, 바람 소리, 궤적 효과로 표현한다. 카메라 롤은 기본 꺼짐, 화면 흔들기는 최소로 한다.

### 4. 와이어와 캐릭터 속성
- 와이어 발사 속도: 갈고리가 목표에 도달하는 속도. 느리면 연결이 늦어지고 빨라지면 복구가 쉬워진다.
- 와이어 당김 속도: 연결 중 줄 길이를 줄이는 속도. 캐릭터를 항상 앵커에 직선으로 끌어당기는 힘과 구분한다.
- 와이어 최대 길이: 연결 가능 거리와 최대 줄 길이. 기본 스윙만으로 필수 경로를 통과할 수 있어야 한다.
- 보조 속성: 공중 조향, 경험치 획득 반경. 속성 수를 무작정 늘리지 않는다.
- 캐릭터 점프력: 출발과 넘어짐 복구, 슬라이드 종료 후 재도약 높이에 적용한다.
- 지상 달리기 속도: 초반 출발과 실패 복구에 적용한다. 정상 스윙보다 느려서 달리기만 하는 것이 최적 전략이 되지 않게 한다.
- 줄 해제 시 현재 속도를 보존한다. 기본 스윙마다 임의 부스트를 주지 않는다.
- 줄이 팽팽할 때만 길이 제약을 적용하고 느슨하면 자유 낙하한다. 바닥 충돌 판정과 스윙 이동은 동일한 물리 시간 기준으로 처리한다.
- 최초 버전은 로프 감기·엉킴·건물 파괴를 구현하지 않는다. 정해진 앵커를 사용하며 줄 경로가 막히면 짧은 경고 후 연결을 해제한다. 앵커 배치로 대부분의 가림을 예방한다.

### 5. 레벨과 경험치
- 전진한 새 거리만큼 기본 경험치가 지속 지급된다. 생존 시간만으로는 경험치를 주지 않아 제자리 파밍을 막는다.
- 경로의 경험치 아이템은 일회성 추가 경험치를 준다. 쉬운 경로에는 소량, 저공 스윙이나 좁은 통로에는 더 높은 보상을 배치한다.
- 초기 테스트값: 새 거리 1m당 경험치 1, 일반 아이템 +15, 위험 경로 아이템 +40.
- 현재 레벨 L에서 다음 레벨 요구량: round(180 × 1.25^(L-1)). 초과 경험치는 이월한다. 이 식은 무한 후반에서 성장이 지나치게 느려질 수 있으므로 레벨업 간격을 측정해 증가율 완화나 상한을 검토한다.
- 레벨업 시 물리·위험 타이머를 정지하고 3개 선택지 중 1개를 고른다. 재개 카운트다운 동안도 정지하고 버튼 해제 상태를 확인해 오발을 방지한다.
- 선택지는 새 능력 획득, 보유 능력 강화, 기본 속성 강화로 구성한다.
- 첫 레벨업에는 롤러스케이트를 반드시 후보로 넣는다. 3레벨까지 양측 사출 장치가 최소 한 번 후보에 등장한다. 테스트 모드에서는 두 능력을 즉시 체험할 수 있다.
- 최대 레벨 능력은 후보에서 제외한다. 장비 슬롯 제한은 첫 버전에 없다. 선택지가 부족하면 미완성 기본 속성이나 소모한 방어구 충전으로 보완한다. 모두 최대라면 레벨업 팝업 없이 경험치를 결과 보너스로 기록한다.
- 빌드는 속도·안정성·저공 이동의 선택으로 나뉘되, 특정 능력이 없어서 통과 불가능한 구간은 만들지 않는다.

### 6. 특수 능력

| 능력 | 최초 획득 | 강화 제안 | 제한과 역할 |
|---|---|---|---|
| 양측 사출 장치(원안: 입체기동장치) | 전방 양쪽 건물의 앵커에 동시에 걸어 짧게 당긴 후 전방으로 사출 | 3단계, 추가 사출 속도 +8/+11/+14m/s | 사거리 고정 40m, 재사용 10초부터 테스트. 양쪽 유효 앵커가 없으면 발동하지 않고 재사용 시간도 소모하지 않음 |
| 충격 방어구 | 치명 충돌 1회 방지 | 최대 충전량 1/2/3회. 강화 선택 시 최대치 +1 및 충전 +1 | 한 충돌 묶음은 한 번만 소모. 안전 위치 복구·외부 방향 속도 제거·1초 무적. 구덩이는 마지막 안전 복구점 사용 |
| 고층 연결망(원안: 양옆 건물 높이 상승) | 앞으로 생성되는 일부 건물에 더 높은 앵커 추가 | 해당 건물의 추가 높이 +4/+7/+10m | 기존 낮은 앵커를 보존. 화면 속 건물이나 연결 중 건물을 갑자기 변형하지 않음. 위쪽 선택 경로를 제공 |
| 롤러스케이트 | 낮은 충격으로 바닥에 진입하고 와이어를 놓으면 수평 속도를 보존하며 슬라이드 | 최대 거리 25/40/60m | 자동 가속하지 않음. 점프나 재연결로 조기 종료 가능. 높은 낙하 충격과 정면 장애물은 방어하지 못함 |

- 위 숫자는 모두 가설이며 실제 게임 스케일에 맞춰 조정한다.
- 양측 사출은 업그레이드할 때 속도 하나만 올려 효과를 명확하게 한다. 사거리까지 동시에 늘려 다른 속성 업그레이드를 압도하지 않는다. 최종 속도 상한은 별도로 둔다.
- 건물 높이 증가가 반드시 쉬운 스윙을 보장하지는 않는다. 낮은 앵커와 높은 앵커를 함께 제공하고 기본 사거리에서 사용할 수 있는지 검증한다.
- 롤러스케이트는 공중 스윙의 대체가 아니라 다음 스윙으로 이어지는 동작이다. 바닥의 낮은 장애물과 끊어진 구간이 재도약 시점을 만든다.

### 7. 바닥 충돌과 슬라이드 — 최우선 설계
- 전체 이동 속도가 아닌 충돌 직전 표면 법선 방향 진입 속도로 충격을 판정한다. 수평으로 빠르게 움직이며 바닥을 스치는 것은 큰 낙하 충격과 구분한다.
- 초기 가설: 바닥으로 향하는 수직 속도 4m/s 이하는 저충격, 초과는 치명 충돌이다. 테스트 결과로 경계값을 조정하며 착지 가능 표시를 제공한다.
- 롤러스케이트가 없으면 저충격 착지 시 수평 속도 0, 약 0.6초 넘어짐 후 자동 달리기로 복구한다. 출발 때 서 있는 상태나 이미 달리는 상태의 접촉은 새 착지로 판정하지 않는다.
- 롤러스케이트가 있으면 저충격 착지 + 수평 속도 8m/s 이상 + 해제 타이밍 성공 시 슬라이드한다.
- 해제 입력은 착지 0.15초 전~0.15초 후까지 허용한다. 착지 후 짧은 판정 대기 상태를 둬 성공 입력 전에 넘어짐이 확정되지 않도록 한다.
- 슬라이드 성공은 수평 속도만 보존하고 수직 속도는 정리한다. 남은 거리를 UI로 보여준다. 만료 후 약 0.4초 동안 달리기 속도로 감속한다.
- 같은 착지에서 반복 발동해 슬라이드 거리를 초기화하지 못한다. 재충전은 실제 공중 상태와 일정 높이 이상의 재도약을 거친 다음 착지에서만 가능하다.
- 실패했지만 저충격이면 넘어짐, 고충격이면 방어구 소모 또는 게임오버다. 모든 바닥 접촉을 즉사 처리하지 않는다.
- 장애물은 정면 충돌 시 치명, 가장자리 스침은 감속으로 분류한다. 복잡한 각도 규칙보다 알아보기 쉬운 충돌 영역과 피드백을 우선한다.
- 달리기만으로 무한 생존하지 못하도록 공중 통과가 필요한 낮은 차단물을 주기적으로 둔다. 별도 추격자 시스템은 첫 버전에 추가하지 않는다.

### 8. 무한맵과 공정한 장애물
- 완전 무작위 배치 대신 검증된 짧은 구간을 조합한다. 앞쪽 청크를 생성하고 뒤쪽 청크를 재사용한다.
- 기본 구간 유형: 스윙 학습 직선 / 낮은 바닥 차단물 / 높이를 낮춰야 하는 상부 장애물 / 앵커 간격이 넓은 구간 / 경험치 유혹 저공 구간 / 슬라이드 뒤 재도약 구간.
- 처음 20초 상당 거리는 안전한 기본 연결을 제공하고 이후 장애물을 하나씩 소개한다.
- 각 청크에는 진입 속도 범위, 기본 앵커, 장애물 높이, 경험치 경로, 출구 상태, 연결 가능한 다음 청크 태그를 둔다.
- 청크 연결부까지 검증하며 앵커·구멍·장애물을 각각 독립 난수로 배치하지 않는다.
- 기본 장비로 통과 가능한 경로를 항상 하나 이상 제공한다. 강화 장비는 더 빠르거나 보상이 좋은 선택 경로를 연다.
- 장애물 예고 거리는 고정값만 사용하지 말고 현재 속도 × 최소 반응시간에 여유를 더해 결정한다. 최소 반응시간 1.5초부터 테스트한다.
- 난도는 최고 진행 거리에 따라 구간 조합을 바꾸되 속도·장애물 밀도·앵커 간격을 한꺼번에 올리지 않는다. 후반에도 반응시간 하한과 최대 난도 상한을 둔다.
- 플레이어와 연결된 앵커가 있는 청크는 제거하지 않는다. 장거리 진행의 좌표 정밀도 문제를 피하도록 구간 재배치/원점 이동 전략을 기획한다.

### 9. 출발 밸런스 제안
아래는 프로토타입 테스트값이며 검증된 정답이 아니다.

| 항목 | 시작값 | 강화 제안 |
|---|---:|---|
| 달리기 속도 | 6m/s | 선택당 +10%, 3회 |
| 점프 높이 | 약 3m | 선택당 +10%, 3회 |
| 와이어 발사 속도 | 80m/s | 선택당 +20%, 3회 |
| 와이어 당김 속도 | 5m/s | 선택당 +15%, 3회 |
| 와이어 최대 길이 | 30m | 선택당 +10%, 3회 |
| 일반 스윙 목표 속도 | 12~22m/s | 느낌을 검증하는 기준 |
| 전체 속도 상한 | 35m/s | 장애물 예고 거리와 함께 검증 |
| 기본 앵커 높이 | 10~18m | 건물 간격과 함께 조정 |
| 초기 도로 폭 | 12m | 양측 연결 가능성 확인 |

- 속성 설명에는 숫자뿐 아니라 실제 효과를 표시한다. 예: ‘와이어가 빨리 연결되어 추락 직전 복구가 쉬워집니다.’

### 10. 저비용 비주얼과 구현 방향
- 박스 건물 6~10종, 도로, 장애물 3종, 캐릭터 1종, 단순 발광 경험치 오브젝트로 시작한다.
- 무료 로우폴리 에셋 한 계열을 주력으로 쓰고 색상·반복층·배치로 변주한다. 건물 전체를 세로로 늘리기보다 반복층/옥상 앵커 구조물을 사용한다.
- 충돌은 단순 박스·캡슐로 분리한다. 화면에만 보이는 디테일에 복잡한 충돌을 만들지 않는다.
- 와이어는 단순한 선 또는 가는 메시로 표현한다. 다관절 물리 로프는 첫 버전에 필요 없다.
- 양측 사출은 두 물리 로프의 경쟁 제약 대신 짧은 제어 상태와 사출 속도로 구현하는 방식을 검토한다. 요구한 체감은 유지하면서 불안정성을 줄인다.
- 캐릭터는 무료 모델 1개, 달리기·점프·공중·스윙·슬라이드·넘어짐 상태로 제한한다. 무료 팩에 스윙/롤러 전용 애니메이션이 포함됐다고 가정하지 말고 확인 후 단순 포즈와 기울기로 보완한다.
- 첫 버전에는 전투, 적 AI, 멀티플레이, 온라인 랭킹, 건물 내부, 실시간 파괴, 캐릭터 커스터마이징을 추가하지 않는다.
- 데이터를 분리해 능력·청크를 추가할 때 여러 파일에 같은 분기문을 반복하지 않도록 한다. 구체적 클래스 구조는 개발 단계에서 정한다.

### 11. 개발 순서와 통과 기준
1. 회색 박스 시험장: 한 줄 스윙, 해제 관성, 점프, 카메라. 성장 없이 60초 반복해도 타이밍에 따른 차이가 느껴지는지 확인.
2. 핵심 차별점: 바닥 충격 판정, 넘어짐, 롤러스케이트, 재도약. 저공 스윙→슬라이드→재연결을 연속 5회 재현할 수 있어야 함.
3. 무한 진행: 검증 청크 6개, 장애물 3종, 거리 기록, 사망·즉시 재시작. 기본 장비에서 불가능한 연결이 없는지 확인.
4. 세션 성장: 거리 경험치·아이템·3택1, 네 가지 특수 능력과 속성 강화. 선택·재개 순간 낙사나 중복 입력이 없어야 함.
5. 무료 에셋 적용과 효과음, UI, 최적화, 플레이테스트. 시각 자산 교체 후에도 충돌과 앵커 위치를 재검증.

### 12. 요청할 최종 산출물
한 문장 게임 소개, 30초 플레이 예시, 조작표, 상태 전이표, 충돌 판정표, 능력 강화표, 경험치 곡선, 청크 6종 배치 설명, MVP 개발 작업 목록과 완료 조건, 비용·시간 가정, 재미를 검증할 테스트 항목을 작성하라. 숫자는 확정값과 조정 가능한 가설을 구분하라. 아직 실행하지 않은 빌드·플레이 테스트를 완료했다고 보고하지 말라.

## 기획상 가장 중요한 판단

1. 거리 기록을 주 목표로 삼고 빌딩 수는 보조로 둔다.
2. 경험치를 시간 대신 새 진행 거리에 연결해 정지 파밍을 막는다.
3. 롤러스케이트는 이 게임의 차별점이므로 나중에 붙이지 말고 첫 조작 시제품에서 검증한다.
4. 건물 높이 업그레이드는 높은 앵커 선택권을 늘리는 방식으로 구현한다. 기존 안전 경로를 없애지 않는다.
5. 스윙이 재미없으면 성장 시스템으로 덮지 말고 먼저 조작을 수정한다.
