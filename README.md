# Wire Rush

건물과 공중 장애물에 한 줄 와이어를 직접 걸어 스윙하고, 플레이어가 낮게 내려왔을 때 줄을 놓고 착지하는 3D 게임 프로토타입.

**v0.13.2 · Godot 4.7.1 · Windows x64 · 한국어/English · 오프라인 싱글플레이**

최근 검증: [City Final QA](docs/CITY_FINAL_QA_0.13.2.md). 개발용 자동 데모·촬영 코드와 과거 프로브를 정리했습니다. 전체 주행·와이어 구간·완료 판정의 검증 범위는 보고서에서 구분합니다.

## 실행과 조작

현재 0.13.2는 Godot 4.7.1에서 `project.godot`을 열어 실행합니다. 기존 `builds/WireRush-0.13.0-Windows.zip`은 이전 후보 빌드이며 최신 보스 모델·QA 수정 사항을 포함하지 않습니다.

- **좌·우 마우스 버튼 유지:** 커서가 가리킨 건물 또는 공중 장애물에 수동 연결하고 자동으로 줄을 감습니다.
- **반대 버튼:** 현재 한 줄을 새 지점으로 옮깁니다. 활성 버튼을 놓으면 관성을 유지하며 해제합니다.
- **먼 곳 조준:** 최대 사거리 부근의 실제 건물·공중 장애물 표면으로 보정합니다. 청록색 보정 표식이 연결될 위치입니다.
- **Space:** 지상·스케이트에서 점프. 이중 점프 코어를 획득한 뒤 공중 추가 점프 가능(벽 점프는 비활성화). **W:** 전진 걷기. **A/D:** 좌우 이동·조향.
- **G:** 쌓인 업그레이드를 원하는 타이밍에 모두 소비(레벨업해도 바로 멈추지 않고 대기 stack에 쌓임). 일반 레벨업은 **일반 업그레이드**(와이어/기동성/모멘텀/생존), 5레벨마다는 **코어 업그레이드**(이중 점프·롤러스케이트·충격 방어구 중 하나)를 제시하며, 대기 중인 항목은 각자의 종류를 그대로 기억했다가 쌓인 순서대로 소비됩니다.
- **Esc:** 일시정지·설정. **R:** 재시작. **1/2/3:** 업그레이드 선택.
- 설정에서는 한국어/English를 즉시 바꾸고 저장할 수 있습니다.

일반 스윙은 수동 한 줄입니다. 두 줄 동시 사출(E)은 제거했고, 대신 공중 이중 점프로 대체했습니다. 벽 점프는 코드는 있지만 실전 확인이 안 돼 비활성화(주석 처리) 상태입니다. 자동 앵커 네트워크와 마우스 두 줄 독립 모드는 사용하지 않습니다.

건물 배치는 기존 배치 비교 실험 중 **건물 간격**(64m마다 좌우 벽이 한쪽씩 번갈아 사라짐) 방식을 기본으로 고정했습니다. 다른 배치 실험(기존 배치/수직 차단벽)과 배치 선택 설정은 제거했습니다. 연습 모드는 항상 양쪽 벽을 모두 배치해 스윙 연습에 집중할 수 있습니다.

## 착지·장비·장애물

**연결된 와이어를 놓는 순간의 플레이어 높이가 5m 이하이면 도로에 안전하게 착지합니다.** 5m 초과에서 놓으면 도로 충돌 시 게임오버이며 방어구·복귀 보호·연습 복구로 막을 수 없습니다. 앵커 위치와 무관하게, 18m 앵커에서 플레이어 높이 4m에 놓으면 생존하고 4m 앵커에서 플레이어 높이 8m에 놓으면 위험합니다. 일반 점프는 예외지만 새 와이어가 실제로 연결되면 예외가 해제됩니다. 벽의 청록색 선과 HUD로 플레이어 높이를 확인할 수 있습니다.

스케이트는 코어 획득 후, 새로운 와이어 연결을 플레이어 높이 5m 이하에서 해제하고 착지할 때 시작합니다. 충전량이 가득 찼을 때 등급별 **2 / 3.5 / 5초** 동안 착지 속도를 유지하며, 완전 충전에 **4 / 7 / 10초**가 걸립니다. 와이어 연결·해제, 점프·착지는 충전량을 초기화하지 않습니다. 점프만 하고 재착지하면 스케이트가 갱신되지 않으며, 다시 연결하고 낮게 해제해야 합니다.

점프 높이와 이중 점프는 별개의 업그레이드입니다. 점프 높이는 지상·이중 점프 높이를 올립니다. 이중 점프 코어는 추가 점프를 해금하고 등급별 재사용 대기를 **10 / 7 / 5초**로 줄이며, 상위 등급에서 공중 제어·다음 와이어 연결 보너스를 줍니다.

건물 높이는 플레이어가 고르는 업그레이드가 아니라, **진행 거리 기반 Difficulty Director**가 결정하는 월드 값입니다(0~3단계). 값이 오르면 그 시점 이후 새로 생성되는 청크만 건물·공중 장애물이 함께 높아지며, 이미 만들어진 청크는 그대로 유지됩니다. 공중 장애물은 64m마다 4개 이상(거리 구간에 따라 증가), 각각 약 **2.6 × 2.2 × 1.4m**입니다. 연결된 장애물 뒤로 스윙해도 줄이 유지되며, 다른 장애물의 줄 가림과 몸 충돌은 위험합니다. 건물 벽은 몸으로 부딪혀도 안전합니다(벽 점프는 비활성화 상태). 도전 첫 128m와 연습 모드는 장애물 없이 시작합니다.

City는 진행 거리에 따라 4단계로 어려워집니다 — **0~500m 안전 도입부, 500~1000m 기본, 1000~2000m 압박(건물↑·차량↑·장애물 수직 분포 확대), 2000m 이후 후반**. 이 진행은 플레이어 레벨·업그레이드와는 완전히 무관하며, 업그레이드를 하나도 찍지 않아도 항상 통과 가능한 경로가 보장됩니다. 2000m 이후에는 짧게 건물이 사라지고 드론만 남는 **Sky Gap** 구간과, 짧게 차량이 평소보다 늘어나는 **Traffic Surge** 구간이 가끔(쿨다운을 두고) 등장합니다 — 둘 다 새 차량/드론 모델 없이 기존 자산만 사용하며, 화면에는 별도 경고 UI 없이 환경 변화로만 드러납니다.

카메라는 현재 `Rules.CAMERA_OFFSET` 기준 약 5m 거리(뒤 4.68m·위 1.76m)이며 마우스로 시점을 조절합니다. 상세 규칙은 [플레이 안내](docs/PLAY_GUIDE.md)에 있습니다.

## City Boss · Rest Area · Story

약 3200m 지점에서 City Boss **"Police Interceptor"**(`boss drone.glb` 모델)가 등장합니다. 체력이나 전투 시스템은 없는 **Traversal Boss**로, 기존 와이어·점프·이중 점프·스케이트·방어구만으로 1500m를 돌파(4700m 지점)하면 클리어됩니다. 세 가지 패턴을 고정된 순서로 반복합니다 — **Path Block**(닫힌 쪽 건물 라인부터 그쪽 도로의 약 1/3 안쪽까지, 도로면부터 현재 건물 최고높이까지의 가로·세로 범위 전체가 위험 구역이 되며, 반대편은 항상 안전), **Laser Plane**(현재 사용 높이를 정확히 절반으로 나눠 위쪽 또는 아래쪽 절반 전체가 위험 구역이 되며, 폭은 양쪽 건물 라인과 그 사이 도로를 모두 덮음 — 반대쪽 절반은 항상 안전), **Robot Barrage**(보스가 좌/중/우에서 장애물 로봇 3기를 짧은 간격으로 직진 발사 — 발사 순간에만 조준하고 이후 추적하지 않는 비호밍 방식, 기존 police drone 비주얼 재사용). Path Block과 Laser Plane은 최종 위험 범위와 완전히 동일한 위치·크기의 붉은 반투명 해치 무늬 경고가 충돌 없이 3회 점멸한 뒤, 밝은 활성 표시로 바뀌며 정확히 2초 동안 충돌이 유지됩니다(방어구로 1회 방어 가능). Boss 구간에는 Sky Gap/Traffic Surge가 겹치지 않으며 차량 밀도도 평소 수준으로 유지됩니다. Boss를 클리어하면 400m 구간의 안전한 **Rest Area**(4700~5100m, 장애물·차량·드론 거의 없음)로 이어지고, 그 끝에서 City Chapter가 완료됩니다. 진행 중 세 번(시작/중반/Boss 클리어) 아주 짧은 자막이 화면 하단에 표시되며, 플레이를 멈추지 않습니다. 보스는 실제 모델과 센서·레이저 VFX를 사용하며 Rest Area는 간단한 검문소 장식으로 구성됩니다. 체력바·경고 팝업 같은 새 HUD는 추가하지 않았습니다.
